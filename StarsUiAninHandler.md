# ClientStarsEffect

`LocalScript` that generates an animated **star effect** with a rotating `Shine` inside specific UI screens (by default, only `ShopScreen`).

> ℹ️ The script runs continuously on the client and only acts when the target screen is **active** (`Enabled = true` and attribute `IsEnabled = true`) and the `Root` is **visible**.

---

## 📦 Requirements

| Path | Type | Description |
|------|------|-------------|
| `PlayerGui.ShopScreen` | `ScreenGui` | Target screen (name must be in `ALLOWED_SCREENS`) |
| `ShopScreen.*.Stars1` | `ImageLabel` / `Frame` | Star template (exact name required) |
| `ShopScreen.*.Stars2` | `ImageLabel` / `Frame` | Second star template (optional) |
| `ShopScreen.*.Shine` | `ImageLabel` | Continuously rotating shine (optional) |

### Expected structure

```
PlayerGui
└── ShopScreen (ScreenGui)
    └── SomeFrame (Frame)  ◄── Root
        ├── Stars1         ◄── Star template
        ├── Stars2         ◄── Star template
        ├── Shine          ◄── Rotating shine
        └── ActiveStarClones (Folder) ◄── Auto-created
```

---

## 🎯 What this script does

The script performs **four main functions**:

### 1. Filters allowed screens

Only processes `ScreenGui` instances whose names are in `ALLOWED_SCREENS`:

```lua
local ALLOWED_SCREENS = {
	["ShopScreen"] = true,
}
```

To add more screens, add a new entry:

```lua
local ALLOWED_SCREENS = {
	["ShopScreen"]    = true,
	["RewardsScreen"] = true,
}
```

### 2. Collects "Roots" (containers with stars)

Searches for descendants named `Stars1` or `Stars2` whose **parent is a `Frame`** and that are **not inside an `ActiveStarClones`** folder (to avoid processing clones generated by the script itself).

The parent `Frame` is considered the **Root** of the effect.

```lua
local function getRoot(star)
	local p = star.Parent
	if p and p:IsA("Frame") then
		return p
	end
	return nil
end
```

### 3. Generates animated stars

For each active Root, the script:

1. Creates (if it doesn't exist) a `Folder` named **`ActiveStarClones`**.
2. Limits to a **maximum of 3 active clones** per Root.
3. Randomly clones `Stars1` or `Stars2`.
4. Assigns a random position (`UDim2.new(math.random(), 0, math.random(), 0)`).
5. Initial scale: **60%** of the original size.
6. Animates growth to a random size between **30% and 100%**.
7. Animates fade-out (`ImageTransparency → 1`) and shrink.
8. Destroys the clone when finished.

### 4. Rotates the `Shine`

If the Root has a child named `Shine`, it connects to `RunService.RenderStepped` and rotates continuously:

```lua
shine.Rotation = (shine.Rotation + 10 * delta) % 360
```

The connection **automatically disconnects** when:
- The screen is no longer active.
- The Root is no longer visible.
- The `Shine` is destroyed.

## ⚙️ Configurable constants

| Constant | Current value | Description |
|----------|---------------|-------------|
| `ALLOWED_SCREENS` | `{ ["ShopScreen"] = true }` | Whitelist of processable `ScreenGui` |
| Max clones per Root | `3` | Hard limit in `createStarEffect` |
| Initial clone scale | `0.6` | 60% of original size |
| Target scale | `random(30, 100) / 100` | Between 30% and 100% |
| Growth time | `0.2 + random() * 0.5` | Between 0.2s and 0.7s |
| Fade time | `0.3 + random() * 0.3` | Between 0.3s and 0.6s |
| Spawn interval | `0.2 + random() * 0.5` | Between 0.2s and 0.7s |
| Shine rotation speed | `10 * delta` | Degrees per second |

## 🔄 Execution flow

```
[Script starts]
   │
   ├─► Filters allowed ScreenGuis (ALLOWED_SCREENS)
   │
   ├─► Connects ChildAdded to detect new screens
   │
   ├─► Every frame (RenderStepped):
   │     │
   │     ├─► For each active screen:
   │     │     ├─► collectRoots() → finds Frames with Stars1/Stars2
   │     │     └─► If Root is visible:
   │     │           ├─► startRootAnimation()
   │     │           │     ├─► Activates Shine rotation (if exists)
   │     │           │     └─► Loop: createStarEffect() every 0.2–0.7s
   │     │           │
   │     │           └─► createStarEffect():
   │     │                 ├─► Creates ActiveStarClones if missing
   │     │                 ├─► Max 3 clones
   │     │                 ├─► Clones random Stars1/Stars2
   │     │                 ├─► Growth tween
   │     │                 └─► Fade tween + destroy
   │     │
   │     └─► Shine rotation
   │
   └─► Loop continues while the script is alive
```

## 🧩 Main functions

### `isScreenActive(screen)`

Returns `true` if the screen is mounted, enabled and has `IsEnabled = true`.

```lua
local function isScreenActive(screen)
	return screen
		and screen.Parent
		and screen.Enabled
		and screen:GetAttribute("IsEnabled") == true
end
```

### `collectRoots(screen)`

Returns a unique list of `Frame` instances containing `Stars1` or `Stars2` (excluding clones).

### `createStarEffect(rootFrame)`

Generates a star clone with appear, growth and fade animations.

### `startRootAnimation(rootFrame, screen)`

Activates the `Shine` rotation and starts the star generation loop for that Root.

### `updateActiveScreens()`

Called every frame; iterates over active screens and starts animations on visible Roots.

## 🎨 Customization

### Add a new screen

```lua
local ALLOWED_SCREENS = {
	["ShopScreen"]    = true,
	["RewardsScreen"] = true,  -- new
}
```

### Change the Shine rotation speed

```lua
shine.Rotation = (shine.Rotation + 25 * delta) % 360  -- was 10
```

### Increase the number of simultaneous clones

```lua
local cloneCount = #clonesFolder:GetChildren()
if cloneCount >= 3 then return end   -- change 3 to another value
```

### Change the spawn probability

```lua
task.wait(0.2 + math.random() * 0.5)  -- faster: 0.1 + math.random() * 0.3
```

### Use only `Stars1`

Rename `Stars2` to something else or delete it from the hierarchy; the script will still work.

## ⚠️ Considerations

- The script **only processes `ScreenGui` whose name is in `ALLOWED_SCREENS`**. If you rename the screen, you must update the whitelist.
- The parent `Frame` of `Stars1` / `Stars2` is considered the Root. If the stars are inside a `Folder`, `ImageLabel` or another container, **they will not be detected**.
- Clones are stored in `ActiveStarClones` to prevent the script from feeding back on itself. **Do not manually delete that Folder** while the script is running.
- `Shine` must be named exactly that. If it doesn't exist, nothing rotates.
- The `task.spawn` loop stops when:
  - The Root no longer has a `Parent`.
  - The screen is no longer active.
  - The Root is no longer visible.
- When `RunService.RenderStepped` disconnects, the `Shine` stops rotating until the screen becomes active again.

## 🧪 Usage example

1. In `StarterGui`, create a `ScreenGui` named **`ShopScreen`**.
2. Inside, add a `Frame` with:
   - An `ImageLabel` named **`Stars1`**.
   - (Optional) An `ImageLabel` named **`Stars2`**.
   - (Optional) An `ImageLabel` named **`Shine`**.
3. Make sure `ShopScreen` has the attribute `IsEnabled = true` when you want it active.
4. Run the game. Stars will appear and the `Shine` will rotate while the screen is active.

> ✅ The effect stops automatically when `ShopScreen.Enabled = false` or `ShopScreen:GetAttribute("IsEnabled") ~= true`. You don't need to disable it manually.
